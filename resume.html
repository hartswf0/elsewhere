Summary

I build working tools for generative media, filmmaking and worldbuilding. Machines now produce more images, video, code and possible worlds than people can inspect, organize or shape; my work turns that abundance into usable instruments: browser-based filmmaking systems, networked 3D environments, and compilers that translate formal languages into interactive experiences. I work by building the system, testing it with real users, watching where it fails, and revising it.
